Capstone Project

Budget Life

Budget Life is a 2D financial tracking system that brings real-time banking, loan management, and budgeting into one cohesive interface. This project focuses on helping users track income, expenses, savings goals, and loan schedules with clarity and control.

The system was built with an emphasis on clean UX, responsive data handling, and simplified financial workflows. It blends utility with an approachable, game-like presentation that encourages regular engagement and smarter spending habits.

Main Menu

The main gateway featuring Save/Load, Options, and Game End controls for a smooth player experience.

Game HUD

Real-time status tracking for Health, Energy, and Hunger, alongside a PHP money counter and active quest tracker.

Sleep Interface

A daily summary showing spending and earnings while advancing the game clock and processing financial deadlines.

Shop System

A dynamic commerce system where players trade items across various locations to manage their inventory.

Academic System

Interactive classroom sessions featuring financial quizzes that reward academic and monetary progress.

Bank System

Sophisticated loan management and savings system with integrated insurance to manage financial risk.

Financial adviser

features the Financial Adviser NPC, who helps players manage their finances and provides guidance on spending money wisely.

Part time-Job

Part-Time Job mini-game, where players earn a payout by serving coffee to customers. Starting a shift locks the player in the area, advances time by five hours upon completion, and is limited to once per day. If the shift is not finished by the 10:00 PM closing time, the player is forced out without pay.
